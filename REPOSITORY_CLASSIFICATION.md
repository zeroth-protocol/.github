# Repository Classification

## PUBLIC-PROTOCOL
Specs, ZIPs, docs, stable SDKs, examples and public test vectors.

## PRIVATE-ENGINEERING
Core implementation, PoVW internals, settlement/order implementation and performance prototypes.

## PRIVATE-SECURITY
Vulnerabilities, exploit reproductions, pentest evidence, embargoed audit findings and independent assurance material not cleared for publication.

## PRIVATE-OPERATIONS
IaC, IAM, production topology, deployment configuration and privileged runbooks.
