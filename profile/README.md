# The Zeroth Protocol

**Economic infrastructure for autonomous AI.**

Zeroth is being developed as an open protocol for autonomous economic agents, with protocol-level requirements for verifiability, settlement integrity, cryptographic agility and post-quantum resilience.

## Open-source posture

**Open by design. Private by default until hardened.**

Public repositories expose specifications, standards, documentation, stable interfaces and test vectors. Consensus-critical implementation, exploit-sensitive security research and production infrastructure remain private until the corresponding release gates are cleared.

## Public repositories

- `zeroth-specs`
- `zeroth-zips`
- `zeroth-pq`
- `zeroth-sdk`
- `zeroth-docs`
- `zeroth-examples`
- `zeroth-test-vectors`

## Status

Zeroth is pre-mainnet. Research qualification artifacts are not production consensus guarantees, and PoVW is distinct from blockchain consensus.
